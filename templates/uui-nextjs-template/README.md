# uui-nextjs-template

A starter template for [Next.js](https://nextjs.org) projects using [UUI](https://uui.epam.com/).

Create project from template:
```sh
npx -- degit@latest epam/UUI/templates/uui-nextjs-template/template my-app
cd my-app
npm install
```

For more information, please refer to:
- [Getting Started](https://nextjs.org/docs/getting-started) – How to create a new app with Next.js.
- [UUI docs](https://uui.epam.com/) – UUI library official documentation.
